# 没有砝码怎么标定

## 水就是最好的砝码

**1 ml 水 = 1 g**，这是国际单位制的定义，白送。

| 手边的东西 | 重量 | 精度 |
|---|---|---|
| 500 ml 量杯装满水 | **500 g** | 误差 <1 g |
| 550 ml 农夫山泉（看瓶身净含量）| **550 g** | 瓶标，±5 g |
| 1 升可乐瓶装满水 | **1000 g** | ±10 g |
| 1 元硬币（第五套钢芯镀镍）| 6.1 g | 10 枚 = 61 g |

**比 20 块钱的砝码准。** 砝码出厂也只有 M1 级（±50 mg）到 M3 级（±50 g）不等，你手上那瓶水误差比 M3 级小。

---

## 但你可能根本不用纠结精度

满度标定只是定个**粗略的换算系数**。真正决定准不准的是固件里那行：

```c
float XW_SCALE = 1.0f;   // 秤发的是克就写 1.0
```

标定偏 5%、10%，后面都能补回来：

```c
cal 500    // 放 500 g 的东西，告诉它真实重量，自动算系数
```

**所以满度标定用 500 ml 水，估个大概就行。**

---

## 具体怎么做

### 方案 A：用量杯或矿泉水（推荐）

1. 空瓶/空量杯放上去，**先按「去皮」归零**
2. 灌满水（500 ml 或 550 ml，按瓶标）
3. **长按「加」键** → 出现 `P-H`
4. 输入 `0500`（或 `0550`）
5. 短按「设置」保存

### 方案 B：如果连量杯都没有

用**空碗 + 自来水**，随便装，然后：

1. 装完放秤上，读数是 X
2. 长按「加」→ `P-H` → **输入一个你猜的数**（比如 `0500`）
3. 保存后看读数变成多少

**如果读数变成 Y，说明标定系数偏了 `Y/X` 倍。** 但这时候秤已经能正常显示了，剩下的交给软件：

```c
cal Y      // 告诉它现在显示的这个值其实是 Y 克
```

**先让它不叫，再让它准。** 顺序不能反。

---

## 顺序很重要

现在这台秤的状态是：

```
蜂鸣器响 → 不在称重界面 → 串口不发数据 → UNO 收不到 → LCD 显示 0
```

**标定的目的首先是让它停下来，精度是次要的。**

所以：

1. **零点标定**（空载 → 长按「减」→ `0000` → 设置）—— 这个必须准，不然全是偏移
2. **满度标定**（放水 → 长按「加」→ 输个数 → 设置）—— 这个估个大概
3. 秤不叫了 → 接 D10 → UNO 能收到数了
4. 用 `cal` 命令精调

---

## 硬币凑法（不推荐但可行）

第五套人民币：

| 面额 | 单枚重量 | 凑 100 g |
|---|---|---|
| 1 元（钢芯镀镍）| 6.1 g | 16 枚 = 97.6 g |
| 5 角（钢芯镀铜）| 3.8 g | 26 枚 = 98.8 g |

**误差累积，而且数着累。** 水倒进去就完事，不用数。

## 一句话

**拿个矿泉水瓶，灌满，看瓶身写着多少 ml，那个数就是克数。**
