## 二、面包板怎么分区（先摆器件，再插线）

面包板横向 63 列，**中间那道槽两侧不通**，同侧一列 5 个孔才通。

```
列 1 ─────── 63
┌─────────────────────────────────────────────┐
│ ○○○○○○ 红轨（整条通）  5V                   │
│ ○○○○○○ 蓝轨（整条通）  GND                  │
│  a b c d e   ← 上半排                        │
│ ══════ 中间槽 ══════                         │
│  f g h i j   ← 下半排                        │
│ ○○○○○○ 红轨  12V                            │
│ ○○○○○○ 蓝轨  12V−                           │
└─────────────────────────────────────────────┘
```

| 器件 | 插在第几列 | 方向 |
|---|---|---|
| HX711 | 4–11 | 引脚朝下，跨中间槽 |
| 继电器模块 | 16–27 | 端子朝外 |
| 74HC595 | 31–38 | **缺口朝左**，左排在 c 行、右排在 f 行 |
| 5461AS-1 | 42–55 | 丝印面朝你 |
| 8 个 220Ω | 58–62 | 竖插，一只一格 |

键盘和 Arduino **不插面包板上**，放旁边，用杜邦线连。

## 三、十二步接线（一步一根，插完一根再下一根）

### 第 1 步 · 两条地先接上（最重要，漏了整机发呆）

1. Arduino `GND` → 左上蓝轨
2. 面包板左上蓝轨 → 右上蓝轨，**一根线跨过去**（这根是共地桥）

### 第 2 步 · 5V 上轨

3. Arduino `5V` → 左上红轨

### 第 3 步 · HX711 四根

4. `VCC` → 左上红轨
5. `GND` → 左上蓝轨
6. `DT` → Arduino `A1`
7. `SCK` → Arduino `A0`

### 第 4 步 · 秤接 HX711

8–11. 悬臂梁 `E+ E− A− A+` → HX711 同名的四个焊盘
（颜色：E+ 粉、E− 灰、A− 紫、A+ 紫。最短路径，别绕）

### 第 5 步 · 继电器控制侧

12. `VCC` → 左上红轨
13. `GND` → 左上蓝轨
14. `IN` → Arduino `D8`

### 第 6 步 · 12V 那一路（和 5V 完全分开，只有地是通的）

15. 电源适配器 **DC 头 → DC 母座转接线**，转出红黑两根
    （电源只有一个接线柱，塞不下第二根杜邦针，必须转接线）
16. 红（+12V）→ 右上**红轨**
17. 黑（GND）→ 右上**蓝轨**
18. 右上红轨 → 继电器 `COM`
19. 继电器 `NO` → 泵正极
20. 泵负极 → 右上蓝轨

### 第 7 步 · 泵的细铜线怎么接

泵只有两根裸铜线，没有杜邦头。三条路，选一条：

- **A（推荐）**：公对母杜邦线，母头那端把铜线对折塞进去，公头插面包板。零成本
- **B（最稳）**：KF301 两位端子，¥2，把线压进去再插面包板
- **C（应急）**：铜线对折成双股直接插面包板孔

剥线只剥 **5 mm**，剥完用胶带把线粘在泵壳上做应力释放 —— 断在泵壳里的没法修。

### 第 8 步 · 保护件（不装会烧，别省）

21. **1N4007**：白环那端接 **泵正极**，另一端接 **泵负极**（反并联）
    - 白环 = 阴极。接反了不但不保护，还把短路路径打开了
22. **1000μF**：**长脚接红轨（+12V）**，**白条端接蓝轨（GND）**
    - 极性电容，接反会鼓包。上电前再看一眼方向

### 第 9 步 · 键盘八根

23–26. 行 `R1 R2 R3 R4` → Arduino `D2 D3 D4 D5`
27–30. 列 `C1 C2 C3 C4` → Arduino `D6 D7 D9 D10`

（注意 **D8 是泵**，跳过去了，不是 D6–D9 连着排）

### 第 10 步 · 74HC595 的电源和两个"最容易漏"

31. 16 脚 `VCC` → 左上红轨
32. 8 脚 `GND` → 左上蓝轨
33. **10 脚 `SRCLR` → 左上红轨（接 5V）** ← 接低就一直清零，屏全黑
34. **13 脚 `OE` → 左上蓝轨（接 GND）** ← 悬空就永远关着输出

这两个脚没接对，最典型的症状是"代码没错、就是一个字都不亮"。

### 第 11 步 · 595 到 Arduino 三根

35. 14 脚 `SER` → `D11`
36. 11 脚 `SRCLK` → `D12`
37. 12 脚 `RCLK` → `D13`

### 第 12 步 · 段选和位选

38–45. `QA QB QC QD QE QF QG QH` → 8 个 220Ω → 数码管 `a b c d e f g dp`
（电阻一只一格，别把两只脚插同一列）

46–49. 数码管 `DIG1 DIG2 DIG3 DIG4` → `A2 A3 A4 A5`（**位选不串电阻**）

**5461AS-1 的脚位**：丝印面朝你，上排 6 个是 `a b c d e f`，下排 6 个是 `g dp DIG1 DIG2 DIG3 DIG4`。
各厂可能微调，接错了不烧，只是段乱。用万用表二极管档点一遍就能确定：红笔按住一个下排脚，黑笔逐个碰其余脚，哪段亮记下来。

## 四、烧录和标定

1. Arduino IDE 装好 **HX711** 库（库管理器搜 `HX711`，作者 bogde）
2. 打开 `demo.ino`，开发板选 `Arduino Uno`，端口选对，上传
3. 上传完打开串口监视器，**波特率 9600**
4. 上电应该看到四位数码管先全亮 `8888` 再变成 `----`
5. **标定**：秤上放一袋 500 g 的米（或任何已知重量）
   - 按键 **S13**，或串口发 `c`
   - 串口打印 `[校准] 已按 500g 标定`
   - 拿掉重物，按 **S11** 去皮
6. **试跑**：秤上放 100 g 米 → 按 **S9** → 看数码管数字往上涨 → 到量自己停

## 五、九个数码管不亮的原因（按概率排）

| 现象 | 原因 | 怎么修 |
|---|---|---|
| 全黑，一位都不亮 | 10 脚 SRCLR 没接 5V | 补线 |
| 全黑 | 13 脚 OE 悬空 | 接到 GND |
| 全黑 | 595 的 16 脚没接 5V / 8 脚没接 GND | 查电源 |
| 某一段永远不亮 | 那根 220Ω 没接好，或段脚接错位 | 逐段量 |
| 全部数字挤在一位上 | 位选 DIG1–4 接错顺序 | 换 A2–A5 的对应关系 |
| 数字左右颠倒 | 数码管脚位和图纸相反 | 万用表点一遍，按实测改 |
| 显示乱码但数字在动 | 段码表 a/g 顺序不对 | 改 `SEG[]` 表 |
| 亮但很暗 | 220Ω 太大 | 换 100Ω（别短路，会烧 595） |
| 数字抖/闪 | 位选扫描太慢 | 已经 8 ms 一屏，再抖就是电源问题 |

## 六、四个"一定会踩"的坑

1. **共地**：12V 电源的负极 **必须** 接 Arduino GND。不接的话继电器指示灯会乱闪，泵要么不转要么一直转。
2. **泵必须独立 12V 供电**：不能吃 Arduino 的 5V。泵启动瞬间 0.3 A 冲击会把板子拉复位。
3. **595 的输出不要直接驱动数码管而不串电阻**：一位亮起来是 8 段 × 20 mA = 160 mA，远超 595 单脚 35 mA 的极限，会烧。必须每段串 220Ω。
4. **面包板电源轨可能中途断开**：便宜的面包板红蓝轨中间有断口。插之前用万用表蜂鸣档量一下整条通不通。

## 七、答辩能讲的三句话

1. **不是按秒数加水，是按重量加** —— 泵老化、管路堵了都不影响结果，因为判断依据是秤上的数字。
2. **提前 5 g 断流** —— 泵停之后管子里的水还会流下来几克，所以代码让它提前停，而不是等到了再停。
3. **30 秒没加够就强制停** —— 这是防溢水的最后一道保险，泵卡死也不会一直转。
