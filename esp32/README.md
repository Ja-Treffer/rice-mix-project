# RiceMix on ESP32

用 ESP32 重做的米水配比机。称重换成 XW112（UART 四线，自带去皮），
蜂鸣器 / 温湿度 / 光敏 / 土壤探头全部移除，水位计保留。

三条控制路径，任何一条能用就不算断：

| 路径 | 前提 | 能做 |
|---|---|---|
| 4×4 键盘 | 什么都不需要 | 去皮、开始、急停、翻页 |
| 手机网页 | 连上同一个 WiFi，或连机器自己开的热点 | 全部功能 + 实时读数 |
| MQTT（巴法云） | 有外网 | 异地控制 + 数据上云 |

---

## 一、跟原来的浇花版差在哪

原 `wifi(1).ino` 是「土壤干了就浇」，闭环的是**土壤湿度**；这版闭环的是**重量**。
传感器换掉之后，控制律完全重写，但网络那一层和 LCD 那层沿用。

| 原来 | 现在 | 为什么 |
|---|---|---|
| DHT11 温湿度（GPIO4） | **删除** | 跟配米水无关 |
| 光敏（GPIO35） | **删除** | 同上 |
| 土壤湿度（GPIO33） | **删除** | 换成重量，这才是真正要控的量 |
| 有源蜂鸣器（GPIO15） | **删除** | 噪音源，故障走 LCD 和网页 |
| **水位计（GPIO34）** | **保留** | 防干烧，泵空转会把泵烧了 |
| **L298N 双路（18/19）** | **保留** | 泵线能拧在端子上，比散件整齐；顺带白捡一个反转冲管 |
| HX711 + 24 位 ADC | **XW112 UART** | 模块自己算好克数、自己去皮，省掉整条标定链路 |
| 5461AS-1 + 595 | LCD1602 I2C | 显示内容要能换，I2C 两线更省 IO |

MQTT 平台没换，还是巴法云，只是主题名换了：原来 `pump`/`auto` → 现在 `mixcmd`/`mixdata`。

## 二、先认清这台秤

欣薇 `XW112` V1.0，一颗 **STC8H1K28** 单片机加独立 ADC，固件 `U-1.3`。
它是一台能独立工作的完整电子秤，**但对外有串口**，重量数据是能读出来的。

厂商说明书把它写得很清楚（`E:\hardness\ricemix\esp32\112.pdf`），下面全部照抄，不是推测：

| 项目 | 参数 |
|---|---|
| 波特率 | **9600** |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验 | 无 |
| 帧格式 | `<数字>\r\n`，例如 `0123\r\n` 表示 **123 克** |
| 发送时机 | 只在**称重界面**发；进菜单、标定、测试模式时静默 |

### 四根针：VCC / TX / RX / G

**必须交叉接**，这是新手最容易翻车的地方：

| 板子 | 接 ESP32 | 说明 |
|---|---|---|
| VCC | 扩展板 `3V3` | 不要 5V |
| **TX** | **GPIO4** | 板子在发，我们收 |
| RX | GPIO16 | 我们发，板子收（暂时用不上） |
| G | `GND` | |

TX 接 TX、RX 接 RX 是错的，一定要交叉。接反不会烧，只是收不到数据。

### 传感器四线（板子左上角白色座，不用动）

| 颜色 | 含义 |
|---|---|
| 红 | E+ 激励正 |
| 黑 | E− 激励负 |
| 白 | **S−** 信号负 |
| 绿 | **S+** 信号正 |

接反的表现是读数负数、不动、或者越称越飘。

### 串口什么时候不说话

这是排查时最该先想到的一条。说明书原文：「仅在称重界面、无标定、无菜单、非测试模式时发送」。

所以如果你给秤上电、按了菜单、或者它自己跳进了标定，串口就是安静的，一个字都没有。
**先把数码管按回正常的重量显示，再看串口。**

发送节奏由菜单里的 `ts` 控制：

| ts 值 | 行为 |
|---|---|
| `0.0` | 重量变化时才发，最快每秒 3 次 |
| `>0` | 每 ts 秒发一次（出厂默认 0.5 秒） |

### 开机自检：几秒钟判断线通不通

`setup()` 末尾自动跑 `hxSelfTest(8)`，监听 16 秒：

```
[xw] listening 16s at 9600 baud...
[xw] ALIVE — 31 bytes in 16s. Weight is on the wire.
```

或者：

```
[xw] SILENT — no bytes at all.
     1) swap RX/TX, 2) confirm the scale is on the weighing screen,
     3) try 9600 then 4800, 4) check common ground.
```

`SILENT` 就按那四条查，按顺序。第一条（对调 TX/RX）能解决一半以上的情况。

### 单位：出厂是克，如果你的不是

说明书说 `0123\r\n` 是 123 克，所以固件默认 `XW_SCALE = 1.0f`。

但如果这块表的小数点菜单（`dot`）被设成 `0.000(kg)`，它可能直接发 kg 数值，
表现是**读数小了一千倍**——放 100g 只显示 0.1。这时候：

```
cal 100        # 放 100g 砝码/整袋米，告诉它真实重量
```

固件会自动算出 `XW_SCALE` 并打印出来。也可以直接改源码里那个常量。

### 秤自己那套标定和去皮，别去动

它有四个按键：设置 / 移位 / 加 / 减，长按加键进 `P-H` 满度标定，长按减键进 `P-L` 零点标定。
这些**是它自己的**，标好了存 EEPROM，我们不需要接管。

我们要做的是另一件事：**软件零偏**。因为要在放米之前把空碗减掉。

```c
void xwTare() {
  weightNow  = 0;
  riceWeight = 0;
}
```

两道去皮互不干扰：它的键管它那四个数码管，我们的零偏管算水量的起点。

### 万一串口真的读不出来

拆悬臂梁，接 HX711 模块。线色对应 `红E+ / 黑E− / 绿S+ / 白S−`，
HX711 那侧 `DT→GPIO4`、`SCK→GPIO16`、`VCC→3V3`、`GND→GND`。

固件里有 HX711 的位操作实现，改一个 `#define USE_HX711 1` 就切过去，其余代码不用动。

## 三、接线

### 先说这块板

ESP32 不是裸板，是插在**紫色 38 针扩展板**上的。扩展板把两侧的脚全引出来成母座，
中间插 ESP32，左边还有 DC 5–12V 输入和板载稳压。

这带来三个好处，直接影响接线方式：

- **不用自己搭电源轨**。扩展板左下角有 `5V / 3V3 / GND` 排针，传感器和小模块直接从这里取电。
- **不用往 ESP32 上直接插杜邦线**。那排针太密，插拔几次就松。所有线接扩展板的母座。
- **DC 输入可以走 5–12V**，板载 AMS1117 降压，比从 USB 取电稳。

下面所有「ESP32」的接法，实际都指**扩展板上对应的母座**，引脚编号按扩展板丝印找。
图里只标了本项目用到的 12 个脚，其余脚空着不用——**具体脚位以你手上那块板的丝印为准**，
不同厂家的排列顺序会差一两格。

### XW112 称重模块

| XW112 4pin | 接 ESP32 |
|---|---|
| VCC | 扩展板 `3V3` |
| TX | `GPIO4`（我们的 RX）|
| RX | `GPIO16`（我们的 TX，暂时不接也行）|
| G | `GND` |

四根线，交叉接。TX 对 TX 是错的。

### 水泵

| 从 | 到 |
|---|---|
| 12V 电源 + | L298N +12V |
| L298N OUT1 | 泵红线 |
| L298N OUT2 | 泵黑线 |
| **12V 电源 −** | **L298N GND 和 ESP32 GND** |

L298N 的 `+5V` 端子别接。那是它自己稳压出来的 5V，电流很小，给 ESP32 供电会掉电重启。
| L298N IN1 | GPIO18 |
| L298N IN2 | GPIO19 |
| L298N ENA | 跳线帽接 5V |

最后那根共地是所有人都会漏的一根。两套电源，一个地。没有它继电器指示灯会乱闪，
泵该停的时候不停。

泵线是裸铜头。把线头对折一次塞进杜邦线的母头，公头插面包板。再用胶带把线缆
绑在泵体上，别让拉力全压在接头上。

### 水位计

| 水位计 | ESP32 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| OUT | GPIO34（只输入，不能输出，正好） |

### LCD1602 (I2C)

| LCD | ESP32 |
|---|---|
| VCC | 5V |
| GND | GND |
| SDA | GPIO21 |
| SCL | GPIO22 |

地址默认 `0x27`。屏幕上没有背光就换个地址试 `0x3F`。

**这块屏不显示重量。** XW112 自己带数码管，克数它已经报了，LCD 再抄一遍是浪费——
整块屏只有 32 个字符。它显示的是秤答不出来的四件事：进度、健康、网络、上次结果。
翻页用 S4 或网页。

### 4×4 键盘（可选）

| 键盘 | ESP32 |
|---|---|
| R1 R2 R3 R4 | GPIO32 33 26 27 |
| C1 C2 C3 C4 | GPIO13 14 18 19 |

这八个脚**全部避开了 ESP32 的 strapping 脚**（0 / 2 / 12 / 15）和 flash 脚（6–11）。
按键板不插面包板，直接放桌上，八根杜邦线拉到板子。

只用四个键：**S1 去皮、S2 开始、S3 急停、S4 翻页**。S5–S16 接了但不响应。

### 引脚总表

| GPIO | 用途 | 备注 |
|---|---|---|
| 2  | 板载 LED | 泵转就亮 |
| 13 14 5 4 | 键盘列 | 上拉输入；18/19 归 L298N |
| 16 17 | XW112 RX / TX | UART2 |
| 21 22 | I2C SDA / SCL | LCD |
| 18 19 | 泵（L298N IN1 / IN2） | 18 高 19 低 = 正转 |
| 26 27 | 键盘行 3 / 4 | |
| 32 33 | 键盘行 1 / 2 | |
| 34 | 水位计 | 只输入，无内部上拉 |

## 六、三种用法

### 键盘（断网也能用）

空碗放秤上 → **S1** 去皮 → 倒米 → **S2** 开始 → 泵自动加水到量停。
出任何状况按 **S3**，立刻断电。

**S4** 翻页，四页循环：

| 页 | 第一行 | 第二行 |
|---|---|---|
| 0 进度 | `####...... 45%` 十格进度条 | ` 54.0 / 144.0 g` 已加 / 目标 |
| 1 健康 | `FILL  tank 62mm` 状态 + 水箱 | `flow 12.0 g/s pump*` 实测流量 |
| 2 网络 | `RiceMix` 或路由器 SSID | `192.168.4.1  -52dB` IP + 信号 |
| 3 上次 | `#3 rice100 g` 第几批 + 用了多少米 | `w120 g 10.4s` 加了多少水 + 耗时 |

故障时第 1 页第二行直接显示原因（`!timeout` / `!no flow` / `!no water`），不用翻页。

### 手机网页

连上同一个 WiFi（或机器自己开的热点 `RiceMix` / `12345678`），浏览器开：

- 连热点时：`http://192.168.4.1`
- 连路由器时：看 LCD 第四页显示的那个 IP

页面上有实时重量、目标、已加、水位，四个按钮（去皮/停止/开始/清故障），
还有一个改比例的输入框，改完写进 EEPROM，断电不丢。

### MQTT（巴法云）

| 方向 | 主题 | 内容 |
|---|---|---|
| 下发 | `mixcmd` | `tare` / `start` / `stop` / `clear` |
| 上行 | `mixdata` | `{"w":123.4,"rice":100.0,"tgt":120.0,"add":23.4,"st":"FILL"}`，每 2 秒 |

巴法云控制台里把这两个主题加到同一个私钥下面，手机端订阅 `mixdata` 就能看数据，
往 `mixcmd` 发字符串就能控制。

## 七、校园网这件事

学校的 WiFi 分两种，ESP32 只认第一种：

**能连的**：普通 WPA2 热点、宿舍的独立路由器、手机热点。
SSID + 密码填进去就行。

**连不上的**：eduroam、校园统一认证、网页弹窗登录、802.1X 企业认证。
ESP32 没有浏览器，没有证书链，没有用户名密码认证的能力，物理上做不到。

连不上也不影响使用，代码里已经写好了兜底：**15 秒连不上就自动切成 AP 模式**，
自己开一个叫 `RiceMix` 的热点，手机连上去开 `192.168.4.1` 一样能控制。

校园网环境下最省事的组合是：

1. 手机开热点，SSID/密码填进代码
2. 机器连手机热点
3. 手机浏览器开 LCD 上显示的 IP

这样既不碰校园网认证，也不依赖外网。

## 九、四道保险

任何一道触发都会立刻关泵、状态变 `FAULT`、LCD 第二行显示原因：

| 触发条件 | 说明 |
|---|---|
| `timeout` | 超过 30 秒还没到量 |
| `overload` | 秤上超过 3000 g |
| `no water` | 水位计读数低于 5mm，不许起泵 |
| `no flow` | 泵开了 3 秒，重量涨不到 0.5 g —— 泵空转或管子堵了 |
| `overshoot` | 已加的水超过目标 + 6 g |

`no flow` 这条最有用。泵卡死、进水管脱了、桶里没水，这三种情况的读数表现都是
「重量不涨」，只有这条能抓住。

### 为什么留着 L298N

继电器也能开关泵，而且更便宜。留 L298N 的理由不是电学上的，是机械上的：
**泵线是裸铜头，拧在 L298N 的接线端子上比往杜邦母头里塞可靠得多**，也不会一堆线吊着晃。

顺带多一个白捡的能力——它是 H 桥，反着给电就能倒转。做完一批按 `Flush line`，
泵反转 3 秒，把管子里剩的水推回桶里。下一次配比的起点更干净，误差不会累积。
这个动作用继电器做不出来。

代价是两个 IO（18/19）被占走，键盘列只能退到 GPIO5 和 GPIO4。这两个是 strapping 脚，
但配成 `INPUT_PULLUP` 时上电是高电平，正好是正常启动需要的状态，所以没有风险。

故障状态按 S1 或网页上的 Clear 复位。

## 十一、配套软件 app

`E:\hardness\ricemix\esp32\app\index.html`

一个文件，两种连接方式，手机和电脑都能开。不需要装任何东西。

### 怎么用

**手机或电脑直接用浏览器打开这个文件**（双击即可，file:// 协议就行，不用开服务器）。

打开后先选连接方式：

| 方式 | 怎么连 | 什么时候用 |
|---|---|---|
| **USB 数据线** | 点按钮 → 浏览器弹窗选串口 → 选 CP2102/CH340 | 在桌面上，不想碰网络 |
| **WiFi 局域网** | 填 IP → 点连接 | 手机上，站在灶台边 |

USB 模式需要 **Chrome 或 Edge**（Web Serial 只有这两家支持）。Safari 和 Firefox 用 WiFi 模式。

WiFi 模式下：

- 机器开了热点 `RiceMix` → 填 `192.168.4.1`
- 连同一个路由器 → 填 LCD 第二页显示的那个 IP

### 界面上有什么

- **秤上读数**：大字 + 进度条，进度条颜色跟着状态变（橙=加水、绿=完成、红=故障）
- **四格数据**：目标加水 / 已经加了 / 米重 / 水箱水位
- **四个按钮**：开始配料 / 停止 / 去皮 / 清故障
- **重量曲线**：最近 60 秒，橙色虚线是目标线
- **米水比**：改完点写入，存 EEPROM
- **日志**：每条指令和回复都留痕

### 它和固件说什么话

两种传输，同一套指令词：

| 指令 | 作用 |
|---|---|
| `tare` | 去皮 |
| `start` | 开始配料 |
| `stop` | 停泵（进 FAULT） |
| `flush` | 反转 3 秒冲管（L298N 才有） |
| `clear` | 清故障回 IDLE |
| `ratio 1.6` | 改米水比 |
| `status` | 立刻要一行状态 |

板子每 2 秒回一行 JSON，和 `/api/state` 一模一样：

```json
{"w":121.4,"rice":120.0,"target":144.0,"added":1.4,"ratio":1.20,"water":62,"state":"FILL","fault":""}
```

所以同一个界面，换传输不换逻辑。

### 加到手机主屏幕

用手机浏览器打开后，「添加到主屏幕」。下次点图标直接进，像原生 App——
页面里已经写了 `apple-mobile-web-app-capable` 和 `theme-color`，全屏无地址栏。

### 已知限制

- USB 模式**同一时间只能一个程序占用串口**。Arduino IDE 的串口监视器开着的话，app 连不上，先关掉。
- WiFi 模式下如果 IP 填错，界面会停在「连不上」，改 IP 重连即可，不用刷新。
- 曲线只存在内存里，关掉页面就没了。要留档用串口日志。
