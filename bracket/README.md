# 支架 · 米水配比系统

这个目录是整台机器的**机械部分**：一块底板，上面装 UNO、继电器盒子、泵、键盘，
中间立一个支座托住 5kg 悬臂梁，秤台悬在梁的自由端上方，容器坐在秤台上。

两套图纸，任选或混用：

| 文件 | 用途 | 谁做 |
|---|---|---|
| `stl/` 六个文件 | **3D 打印件**，直接发打印店 | 打印店 / 自己有机器 |
| `bracket_laser.svg` | 激光切割，1:1 排版图，亚克力 5mm（**只含切得出来的件**） | 切割店 |
| `bracket_laser_cut.svg` | **纯几何切割版** —— 零文字、零虚线、单一颜色，直接发店 | 切割店 |
| `bracket_laser.svg` | 带尺寸标注的参考版（有字，**不要发店**） | 自己看 |
| `bracket_assembly.svg` | 装配示意图（俯视 + 高度栈），给你自己看的 | — |

### 为什么切割图要分两版

激光切割软件把 SVG 读进来时，**几乎所有元素都会进切割层**：

- `<text>` 会被当成轮廓切成字 —— 整块板子挖满乱七八糟的字形
- `stroke-dasharray` 虚线会被当成「划线」工艺，切一半深度
- 不同颜色的线，有的软件分图层、有的直接一锅端

所以交给店的必须是零文字、零辅助线的纯几何版。带标注的那张只用来自己核对尺寸。想验证发出去的文件是否干净：

```bash
grep -c '<text' bracket_laser_cut.svg        # 必须输出 0
grep -c 'dasharray' bracket_laser_cut.svg    # 必须输出 0
```

### 发给切割店时说这三句

> 1. 按 1:1 实际尺寸输出，**不要缩放**（文件是 710mm 宽，转 DXF 时注意别把 mm 当成 inch）
> 2. 红线全部切穿，材料 5mm 亚克力
> 3. 孔径比标准略小是正常的 —— 请按你们的**切缝补偿（kerf）**处理，孔是给 M3/M4 螺丝穿的

**打印件清单**（都在 `stl/` 里，单位 mm）：

| `01_pedestal_base.stl` | 支座 | 56×70×19.5 | 顶面有梁槽和挡墙，切不出来 |


## 一、尺寸

### 底板

```
340 × 210 × 5      亚克力或 3mm 胶合板（5mm 才不翘）
```

| 位置 | 干什么 | 孔径 |
|---|---|---|
| x 12 / 78, y 20 / 73.3 | UNO 四角（M3） | φ3.3 |
| x 12 / 56, y 100 / 120 | 继电器盒底面（M3） | φ3.3 |
| x 250 / 316, y 150 | 泵两只耳朵（M3） | φ3.3 |
| x 150 / 190, y 154 / 202 | 支座 4×M3 自攻 | φ2.9 |
| x 258 / 318, y 28 / 88 | 键盘框四角 | φ3.0 |
| (100, 60) (232, 60) | 走线孔 | φ9 |

### 支座与梁

```
支座 56 × 64 × 15        打印件，顶面开梁槽
悬臂梁 80 × 12.7 × 2     成品 TAL220 类，不要自己切
```

梁的**固定端** y=202（支座靠后一侧），朝 **-Y（朝人）** 悬空伸出 80mm，自由端 y=122。
两个 M4 孔在 y=186.8 与 171.8，都是距梁端 15.2、间距 15 —— 对着你手上的梁量一下再打。

受力孔 y=134.7，**秤台中心必须正对它**，否则容器偏心会让四角读数不一致。

### 秤台与高度

```
秤台 150 × 150 × 5      中心 1×M4（φ4.6）+ 3×φ6 定位销，120° 分布，R62
```

高度栈（从桌面往上量）：

| 层 | 厚度 | 顶面高度 |
|---|---|---|
| 底板 | 5 | 5 |
| 支座 | 15 | 20 |
| 悬臂梁 | 2 | 22 |
| M4 铜柱 | 6 | 28 |
| 秤台 | 5 | 33 |

**关键间隙**：秤台底面 28，支座顶面 20 —— 中间空 8mm，秤台压的是梁的自由端，不碰支座。
这个 8mm 是整台机器能不能称准的命门，装的时候用手电筒照一下，别让秤台蹭到支座。

### 管架（把管口钉死在容器正上方）

泵的硅胶管如果只是搭在杯沿上，三个问题会同时发作：管子自重让管口下垂、泵启动瞬间水流的反冲让管子甩动、管口位置每次都不一样。结果就是流量忽大忽小，提前断流的提前量估不准，同一杯米两次配出来的水差十几克。

所以需要一个**独立的管子支架**，它立在底板上、不碰秤台：

```
POST_D = 8      立杆外径，Ø8 亚克力圆棒 / 铝管都行
POST_H = 220    立杆高度（出底板面）
POST_X = 295    立杆位置
POST_Y = 185
ARM_L  = 135    横臂长度：立杆中心 → 管夹中心
PIPE_OD = 10    夹孔内径（Ø8 硅胶管的外径，Ø10 管改成 12）
PIPE_SLOT = 7   夹子开口，比管径小 3mm，管子按进去卡住
```

立杆下端穿过一个 26×26 的底座，底座一个 M4 从底板下面拧上来固定；横臂一端套在立杆上、用 M3 顶丝锁高度，另一端 C 形夹斜着伸到容器中心正上方。管口离杯口水面上方 30mm 左右最合适 —— 太高会溅，太低会插进水里。

**立杆装在 x=295 是为了避开秤台投影（x 95..245）**，它只跟底板发生关系，任何重量都不经过它，所以在它的位置上放什么都不会污染读数。

## 二、装配顺序

1. 底板按图钻孔。**先钻 φ2.9 的支座自攻孔**，比 3.3 小，自攻螺丝才咬得住。
2. 支座用 4×M3 自攻拧在底板上，梁槽朝 -Y。
3. 悬臂梁固定端坐进槽里，2×M4 从梁上方穿下拧进支座 —— **加平垫**，不然梁会被螺丝头压弯，零点偏移。
4. M4 铜柱（6mm）拧进梁的受力孔。
5. 秤台中心孔套在铜柱上，1×M4 从秤台上面拧下来锁住。
6. 三个 φ6 定位销插进秤台，翻过来站不住就对了 —— 它们是给容器定位的。
7. UNO、继电器盒、泵、键盘框依次上板。
8. 管架底座用 M4 从板下拧紧，Ø8 立杆插进去到底，横臂套上立杆、M3 顶丝锁在 200mm 左右高度。
9. 容器围挡四片插接成方框，坐在秤台的定位销内。

装完先空载上电跑 `ZERO`，再放 500g 标准砝码跑 `CAL 500`。**别倒着来**。

## 三、3D 打印参数

| 项 | 值 | 为什么 |
|---|---|---|
| 材料 | PLA 够用，PETG 更稳 | 支座不受力，PLA 就行 |
| 层高 | 0.2mm | — |
| 墙数 | 3 层 | 支座是承力件，2 层会被螺丝撑裂 |
| 填充 | 40% 网格 | — |
| 支撑 | 支座需要（梁槽悬空） | 槽口朝下打，支撑好拆 |
| 摆放 | 支座**平躺**打，槽朝上 | 立着打层间结合弱，M4 一拧就裂 |

泵夹是 L 型，**必须竖着打**（平躺会有 58mm 的悬空跨度）。打印完用 M3 自攻直接拧进塑料。

管架横臂平躺打，C 形夹的开口朝 -Y（避开臂的方向），不需要支撑。套孔 φ8.4 打出来会略小，用 Ø8 钻头或圆锉修一下，能塞进立杆但有点紧正好 —— 太松顶丝锁不住。

## 四、激光切割参数

- 材料：亚克力 5mm（3mm 也行，但底板会翘，得加加强筋）
- 切割缝补偿：0.1–0.15mm（跟店家说「按实际孔径切」就行）
- 图纸是 **1:1**，打印/导出 PDF 时务必选「实际大小 / 100%」，别让打印机缩放
- 红线的都是切穿，青色文字是标注，**不要切**

能切：底板、秤台、容器围挡、键盘面板、管架底座（切两片 3mm 叠起来当 6mm 用）。
**不能切**：支座（有梁槽和沉孔，是三维的）、泵夹（L 型折弯）、管架横臂（C 形夹是圆的）。

## 五、四处必须量实物再改的地方

1. **`PMP_PITCH = 66`** —— 泵两只耳朵孔的间距。AD20P-1230C 是 66，你买的要是别的型号，卡尺量一下改这个数，泵耳的孔跟着动。
2. **`BEAM_END_FIX / BEAM_END_LOAD / BEAM_PITCH`** —— 悬臂梁的孔位。TAL220 是 15.2 / 12.7 / 15，国产梁常见 15 / 12.5 / 15 或 20 / 15 / 20，**按你手上的梁实测**。梁孔打错，整个称重就废了。
3. **`KP_W / KP_D / KP_CUT`** —— 键盘面板尺寸。你的 4×4 轻触按键板是 76×76 开 70，薄膜键盘是 70×70 开 64，两者螺丝孔位置也不同。
4. **`PIPE_OD`** —— 硅胶管的外径。软管标的是内径（常见 Ø6 / Ø8），外径要卡尺量：内径 8 的硅胶管外径一般 10–11，那就填 10 或 11。夹孔小了塞不进去，大了夹不住会滑。

改完这四个数，重跑 `node E:\hardness\_laser2.js`，两张 SVG 会自动跟着变。

## 六、为什么这么摆

秤台 150 深、梁 80 长，两个叠起来 230mm，比底板 210 还长 —— 所以梁不能朝里伸，只能朝外（-Y，朝人）悬空伸出去 80mm，让秤台压在它的自由端上。

这样底板只承担「支座 + 电控 + 键盘 + 泵」的占地，秤台和容器全部悬在板外上方，重心落在板内靠后的支座上，桌子被压翻的概率最低。

左侧 x<142 全给电控（UNO + 继电器盒 + 走线孔），右侧 x>198 给键盘和泵，秤台投影 x 95..245 正好卡在两者之间的空档上 —— 从上往下看是叠着的，但从侧面看是三层：底板 5、支座 20、秤台 28。

管架立在 x=295，是秤台投影（x 95..245）之外最早能站人的位置：再往左会压到秤台，再往右就顶到泵和键盘了。它的横臂斜着跨 135mm 伸到容器中心上方 —— 之所以是斜的，是因为立杆必须避开秤台，而管口必须对准容器中心，两点连线天然有夹角。斜臂反而比正对着好：泵的软管从立杆这一侧过来，顺着斜臂走一圈正好做一个小 U 弯，水流的冲击被这个弯吃掉一部分，管口更稳。

## 七、3D 打印还是激光切割

**混着做最好：大平板切，小三维件打。**

| 零件 | 推荐 | 为什么 |
|---|---|---|
| 底板 340×210 | **激光**（亚克力 5mm） | 大平面，切 1 分钟，打印要 6 小时还会翘 |
| 秤台 150×150 | **激光** | 承重面必须平，打印件平面度靠不住 |
| 容器围挡 ×4 | **激光** | 纯 2D 件，插接结构 |
| 键盘面板 | 激光 | 一块平板开个方孔 |
| 管架底座 | 激光切两片叠 / 打印 | 6mm 厚，切两片 3mm 用 M3 螺丝夹住也行 |
| 支座 56×64×15 | **打印** | 有梁槽、M4 沉孔、圆角，三维件 |
| 泵夹 L 型 | **打印** | 折弯件，亚克力热弯会炸裂 |
| 管架横臂 | **必须打印** | C 形夹是圆的，激光切不出来 |

只能选一种的话选 **3D 打印** —— 激光切不了支座、泵夹、横臂这三个关键件，缺了装不起来；反过来底板用打印件虽然慢、还得多加厚到 6mm 防翘，但能凑合。

**成本**（国内网购代工，2024–2025 参考价）：

| 方式 | 内容 | 价格 |
|---|---|---|
| 激光（全亚克力 5mm） | 底板 + 秤台 + 围挡 + 键盘面板，600×400 板一块 | 60–100 |
| 打印（PLA，代工） | 支座 25g + 泵夹 30g + 横臂 15g ≈ 70g | 20–40 |
| 混着做 | 上面两项 | **80–140** |

自己有打印机的话材料费 10 元以内；有激光渠道的话亚克力按板买更便宜。

**两个实际坑**：

1. **亚克力会翘**。340×210 的 5mm 板放在不平的桌面上，中间会虚 1–2mm，压上泵和电控后更明显。加四个橡胶脚垫就能压住 —— 反正秤台是独立悬空的，底板翘一点不影响称重，只影响观感。
2. **打印孔径会缩**。图纸上 M3 是 φ3.3，打印出来实际只有 φ3.0–3.1，螺丝塞不进去。要么把打印件的孔全改成 φ3.5，要么直接用 M3 自攻拧进 φ3.0 —— 后者更结实。激光切的孔是准的，φ3.3 就是 φ3.3。

## 九、一颗螺丝都不用：全胶接版

买不到螺丝不要紧。把 `bracket.scad` 顶部的 `NO_SCREW` 改成 `true`，整套结构会自动切换成胶接 + 扎带 + 过盈压配，**一颗螺丝都不需要**。

只需要买两样，五金店、超市、甚至快递驿站都有：**AB 胶一支（10 元）、尼龙扎带一包（5 元）**。

### 各处怎么固定

| 部位 | 无螺丝做法 |
|---|---|
| 支座 → 底板 | AB 胶平面粘接，胶接面积 56×64 = **3584 mm²** |
| 悬臂梁 → 支座 | 插进加深的槽里（两侧各加了一道 4mm 挡墙兜胶），从槽口灌 AB 胶 |
| 秤台 → 梁 | 秤台中线上开了两个 φ3.2 孔，**尼龙扎带**穿下去绕过梁的受力孔、拉回来收紧 |
| 管架底座 → 底板 | AB 胶 |
| 立杆 → 底座 | 孔改成 φ8.2 过盈，涂胶压入 |
| 横臂 → 立杆 | 孔改成 φ8.5 松配，高度调好后点一滴热熔胶；以后加热就能改 |
| 泵 | `clamp()` 变成一个 68×40×20 的凹槽座，泵横放进去，四周点胶（前壁开了个口给接头和软管出） |
| UNO / 继电器 / 键盘 | 3M 双面胶或热熔胶，直接粘 |
| φ6 定位销 | 亚克力棒切 10mm，同样点胶 |

### 为什么胶接反而更可靠

梁的固定端要承受 5kg 满载的剪力，约 50 N。胶接面积 12.7×15.2 = 193 mm²，需要的抗剪强度只有 **0.26 MPa**；而环氧 AB 胶固化后抗剪强度 10–15 MPa。**安全系数 40 倍以上。**

螺丝反而会松 —— 泵一振动，M4 螺纹慢慢退扣，两个月后零点就飘了。胶不会。

### 唯一的代价

**粘死了拆不开**。所以要按这个顺序装，装错一步很麻烦：

1. 底板浅坑里涂胶 → 压上支座，用重物压 24 小时（AB 胶要完全固化才有力气）
2. 梁插进支座槽 → 从槽口灌胶 → 同样压 24 小时。**这一步是全场唯一不能赶的**，没固化就上秤台，梁歪了整套报废
3. 秤台放上去 → 扎带穿过两个 φ3.2 孔和梁的受力孔 → 拉紧剪掉尾巴
4. 管架底座涂胶 → 立杆涂胶插入 → 横臂套上、调好高度、点热熔胶
5. 器件最后粘，粘完再接线

如果以后想拆：热熔胶加热就松；AB 胶要泡在开水里 10 分钟软化，或者用美工刀从边缘切。
