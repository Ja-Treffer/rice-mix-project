# 泵空转：先把原因分清楚

「什么都不动，泵会空转」有两种完全不同的情况，对应的解法也不同。

---

## 情况 A：你还没烧固件

**UNO 上电但跑的是空程序（或者旧程序）**，D11/D12 是默认的「悬空输入」状态。

L9110S 的 IA/IB 悬空时输入电平不确定，可能被干扰成高电平 → OA/OB 输出高 → **泵转**。

**这种最常见，也最容易忽略。**

**判断**：串口监视器（115200）有没有看到 `=== RiceMix UNO ===`？

- **没有** → 固件没烧进去，或者烧的是别的程序
- **有** → 进情况 B

---

## 情况 B：固件正常但还是转

### B1. bootloader 那一两秒

UNO 从上电到 `setup()` 跑起来之间，有一段 **bootloader 时间（1–2 秒）**。这段时间所有引脚都是悬空输入，L9110S 照样可能输出高。

**表现**：上电瞬间转一下，`setup()` 跑起来后停。**这是正常的**，不用管。

如果是**一直转不停**，往下看。

### B2. pumpOff() 用了双低

L9110S 真值表：

| IA | IB | OA | OB | 状态 |
|---|---|---|---|---|
| 0 | 0 | L | L | 高阻（理论上不转，但抗干扰差）|
| 1 | 0 | H | L | 正转 |
| 0 | 1 | L | H | 反转 |
| **1** | **1** | **H** | **H** | **刹车（两端同电位，强行制动）** |

**我已经把 `pumpOff()` 从双低改成了双高。** 理由：悬空时 L9110S 更容易跑到「高」，双高正好是刹车状态，泵不动；双低则可能乱跳。

### B3. 硬件没有下拉电阻

这是**根因**。UNO 只有内部上拉（`INPUT_PULLUP`），没有内部下拉。

**彻底解决：IA 和 IB 各接一个 10 kΩ 电阻到 GND。**

```
D11 ──┬── L9110 IA
      │
     10kΩ
      │
     GND

D12 ──┬── L9110 IB
      │
     10kΩ
      │
     GND
```

上电瞬间两个输入被拉低 → 输出双低 → 泵不转。等 `setup()` 接管后，`digitalWrite` 会盖过这颗弱上拉。

**两个电阻几毛钱，这是根治。**

---

## 先按这个顺序试

1. **确认固件烧进去了**——串口能看到 `=== RiceMix UNO ===` 吗
2. 如果看得见还转 → **已经改成双高了，重新烧一次**
3. 还转 → **加两个 10 kΩ 下拉电阻**
4. 没电阻的话，把 **IB 直接接地**，IA 接 D11：

```
L9110S:  IA ← D11    IB ← GND
```

这样 IB 永远是低，只有 IA 会动。上电时 IA 悬空 → L9110S 输出「高-低」→ **泵会转**（这是正转方向）。

**所以这条路不行，IB 接地反而更容易转。**

**实在没电阻**：上电后立刻按 S11（急停），或者接受上电转两秒。

---

## 代码里现在是什么样

```c
void pumpOff() {
  digitalWrite(PIN_PUMP_A, HIGH);
  digitalWrite(PIN_PUMP_B, HIGH);   // 双高 = 刹车
}
```

`setup()` 第一件事就是钉住这两个脚：

```c
void setup() {
  pinMode(PIN_PUMP_A, OUTPUT);
  pinMode(PIN_PUMP_B, OUTPUT);
  pumpOff();          // 先钉死，再初始化别的

  Serial.begin(115200);
  ...
}
```

---

## 一句话

**先看串口有没有输出。没有 = 固件没烧；有 = 加两个 10 kΩ 下拉电阻。**
