# 改造清单 · ESP32 版 → UNO 全硬件版

ESP32 那块烧了，换回 UNO R3。这份对照写清楚：**哪些东西整个没了、哪些换了实现、哪些一行没动。**

---

## 一页看完

| | 内容 |
|---|---|
| **消失了** | WiFi、MQTT 巴法云、网页服务器、手机 App、AP 热点兜底 |
| **换实现** | 泵从 12V+L298N → 5V+L9110S；**LCD 仍是 I2C，但驱动要自己写** |
| **改了脚** | 测重 RX 从 GPIO4 → D10；泵从 GPIO18/19 → D11 |
| **不变** | 状态机、四道保险、8 档配方、三键语义、测重串口协议 |
| **新增** | LCD 四页翻页键（S12） |

一句话：**网络那一半全砍了，控制这一半一行没动。**

---

## 二、为什么会砍掉一半

UNO R3 没有 WiFi，这是硬性的。所以：

| ESP32 有的 | UNO 版 | 影响 |
|---|---|---|
| `WiFi.h` / `WebServer.h` | 没有 | 网页打不开 |
| `PubSubClient` MQTT | 没有 | 手机远程看不了 |
| `/api/state` `/api/cmd` | 没有 | App 连不上 |
| `WiFi.softAP()` 兜底 | 没有 | 校园网 SSO 问题不存在了 |
| 三路控制（键盘/网页/MQTT） | **只剩键盘** | 必须走到机器跟前按键 |

**换来的是稳定**：没有网络层，就没有连不上、掉线、DNS 失败、热点冲突。插上电就能用。

---

## 三、引脚对照

| 用途 | ESP32 版 | UNO 版 | 变化 |
|---|---|---|---|
| LCD SDA / SCL | GPIO21 / GPIO22 | **A4 / A5** | 还是 I2C，只是 UNO 的脚位固定 |
| 键盘行 R1–R4 | 32 33 26 27 | **D2 D3 D4 D5** | 全部数字口 |
| 键盘列 C1–C4 | 13 14 5 17 | **D6 D7 D8 D9** | 连号 |
| 测重 RX | GPIO4 | **D10** | SoftwareSerial |
| 测重 TX | GPIO16 | — | **删**，秤只发不收 |
| 泵 | GPIO18 / GPIO19（L298N） | **D11 / D12**（L9110S 双线） | 泵线接反，要两根线掰回来 |
| 水位 | GPIO34 | **A0** | LCD 占了 A4/A5 |
| 状态 LED | GPIO2 | — | **删**，LCD 够用 |

**为什么键盘能八连**：`D8/D9` 是空的，所以键盘正好占满 `D2–D9` 八个连号口——行 `D2–D5`、列 `D6–D9`，接线时八根线并排走，不用分段。秤用 `D10`、泵用 `D11/D12`，全是连着的；水位落 `A0`，`A1–A3` 和 `D13` 空着备用。

## 四、代码改什么

### 4.1 库

| 库 | ESP32 版 | UNO 版 |
|---|---|---|
| `WiFi.h` / `WebServer.h` / `PubSubClient.h` | 用 | **全删** |
| `Preferences.h`（存比例） | 用 | **删**（改用变量，断电丢失，但配方是固化的不需要存） |
| `LiquidCrystal_I2C.h` | 用 | **换成自己写的 `Wire` 驱动**（系统里没这个库） |
| `SoftwareSerial.h` | 不用（有 Serial2） | **新增**，UNO 只有一个硬件串口 |
| `Wire.h` | 不用（ESP32 有现成 LCD 库） | **新增**，自写 PCF8574 位操作 |

### 4.2 初始化

`setup()` 从「连 WiFi → 起 HTTP → 连 MQTT」那一长串，缩成：

```c
Serial.begin(115200);
for (uint8_t i = 0; i < 4; i++) pinMode(ROW_PINS[i], INPUT_PULLUP);
for (uint8_t i = 0; i < 4; i++) pinMode(COL_PINS[i], INPUT_PULLUP);
pinMode(PIN_PUMP, OUTPUT); pumpOff();
lcd.begin(16, 2);
xw.begin(9600);
```

**没有 `delay(15000)` 等 WiFi 了**，上电一秒就能用。

### 4.3 主循环

ESP32 版 `loop()` 里那一堆：

```c
web.handleClient();
if (wifiUp) { mqttEnsure(); mqtt.loop(); }
```

UNO 版全没了。`loop()` 只剩四件事：

```c
void loop() {
  xwPoll();          // 读秤
  updateLcd();       // 刷屏
  if (state == S_FILL)   runFill();
  if (state == S_SETTLE) runSettle();
  // 键盘 40ms 节流扫描
}
```

### 4.4 测重没变

```c
#define XW_RX 12
SoftwareSerial xw(XW_RX, 255);   // 255 = 不发
xw.begin(9600);
```

解析逻辑和 ESP32 版**一模一样**：`<数字>\r\n`，`atol` 转克。因为秤的协议没变。

**省事的地方**：UNO 是 5V 逻辑，秤也是 5V，**不用分压、不用电平转换**。ESP32 那套 3.3V 的麻烦这里一个都没有。

### 4.5 泵简化了

ESP32 版 L298N 三个脚（IN1/IN2/ENA）支持正反转冲管。UNO 版用 **L9110S 单线正转**：

```c
void pumpOn()  { digitalWrite(PIN_PUMP, HIGH); }
void pumpOff() { digitalWrite(PIN_PUMP, LOW);  }
```

**冲管功能没了**（L9110S 也能反转，但要占第二个脚，UNO 没有富余）。5V 泵 + 短管，不冲也不影响。

## 五、线接在哪

### LCD1602 · I2C 四线（PCF8574 转接板）

| 转接板 | UNO |
|---|---|
| VCC | 5V |
| GND | GND |
| SDA | **A4**（硬件固定） |
| SCL | **A5**（硬件固定） |

**四根线，不是六根。** 你手上这块背面焊了 PCF8574，RS/EN/D4–D7 都已经转到板子上了。

**A4/A5 改不了**：UNO 的 I2C 不像 ESP32 能映射到任意 GPIO，它就是 A4 和 A5 这两根。
所以这两个脚给了 LCD 之后，水位只能挪到 A0。

**驱动是自己写的**：`#include <LiquidCrystal_I2C.h>` 会编译失败——Arduino 自带库目录里
只有并口的 `LiquidCrystal`，没有 I2C 版。固件里用 `Wire` 直接操作 PCF8574 的八个位：
P0=RS、P1=RW、P2=EN、P3=背光、P4–P7=D4–D7。

地址 `0x27`（A0/A1/A2 全短接）。不亮就改 `0x3F` 重烧。
### 4×4 键盘

| 键盘 | UNO |
|---|---|
| R1–R4 | A0 A1 A2 A3 |
| C1–C4 | D8 D9 D10 D11 |

### WX112 秤

| 秤 | UNO |
|---|---|
| VCC | 5V |
| TX | **D10** |
| RX | 不接 |
| G | GND |

### L9110S + 5V 泵

| L9110S | 接到 |
|---|---|
| VCC | 5V（**泵电源单独供**） |
| GND | GND（和 UNO 共地） |
| IA | **D11** |
| IB | **D12** |
| OA | 泵**黑**线（这批货接反了） |
| OB | 泵**红**线（这批货接反了） |

**泵电源别从 UNO 的 5V 取**。USB 只给 500mA，5V 泵启动瞬间能到 1A，会把稳压器拖崩、板子重启。用一个 5V/2A 适配器单独供泵，只把 GND 连起来。

### 水位（可选）

| 水位 | UNO |
|---|---|
| VCC / GND | 5V / GND |
| OUT | A4 |

不装就在代码顶部把 `#define USE_WATER 1` 改成 `0`。

## 六、按键

| 键 | 功能 |
|---|---|
| S1–S8 | 直接选 8 档配方 |
| S9 | 去皮（记空碗） |
| S10 | 开始 |
| S11 | 急停 |
| S12 | 翻 LCD 四页 |

**S9/S10/S11 的语义完全沿用 Uno 老固件**（去皮 / 开始 / 急停），只是把配方选择从「一个键循环」改成了「八个键直选」。

## 七、改完怎么验

1. **只插 USB，泵电源不接**，烧进去
   LCD 应该显示 `RiceMix UNO` / `put bowl + rice`，1.5 秒后清屏进 `READY`
2. **没有背光** → 检查 A/K 那两根和 220Ω 电阻；**有一行黑块** → 电位器没调，拧到字清楚
3. **按 S12 翻页**，四页都能显示 → 键盘 8 根线全通
   只有部分键有反应 → 对应的行或列没插好
4. **秤上放东西**，第二页的 `FLOW` 应该有变化，串口监视器（115200）能看原始值
   一个字节都没有 → 先看秤的数码管在不在称重界面（进菜单就静默），再对调 TX
5. **接泵电源，泵先不接**，按 S10，量 D11 应该 0V、D12 应该跳到 5V
   （泵线接反了，正转靠 IB 拉高）
6. **接泵**，放 50g 米按 S10，看它加到多少

**编译验证**：`avr-g++ -c` 通过，`.text` 3587 字节（32KB 的 11%），`.bss` 142 字节（2KB 的 7%）。**余量很大**，以后加东西不用担心。

## 八、不用动的

- **配方表**：8 档比例和超时一个没改
- **状态机**：`S_IDLE / S_FILL / S_SETTLE / S_DONE / S_FAULT` 五态不变
- **四道保险**：超时 / 超重 / 没出水 / 超量，判断条件和阈值都不变
- **测重协议**：9600 8N1，`<数字>\r\n` = 克
- **控制律**：`target = riceWeight × ratio`，到 `target - lead` 停泵
- **LCD 四页的内容**：进度 / 比例 / 上次 / 故障，只是翻页从网页按钮改成 S12
